Formulas used / القوانين المستخدمة

1. Partial fractions / الكسور الجزئية

A proper rational function (degree of numerator < degree of denominator) is split according to the factors of the denominator:

يُحلَّل الكسر النسبي الصحيح (درجة البسط أقل من درجة المقام) حسب عوامل المقام:

• Distinct linear factors: A/(x−a) + B/(x−b).   • Repeated linear factor: A/(x−a) + B/(x−a)².   • Irreducible quadratic: (Ax+B)/(x²+c).

• عوامل خطية مختلفة: A/(x−a) + B/(x−b).   • عامل خطي مكرر: A/(x−a) + B/(x−a)².   • عامل تربيعي غير قابل للتحليل: (Ax+B)/(x²+c).

If the numerator degree is greater than or equal to the denominator degree, divide first (polynomial long division).

إذا كانت درجة البسط أكبر من أو تساوي درجة المقام، نقسم أولًا (قسمة كثيرة الحدود المطولة).

2. Remainder and factor theorems / نظرية الباقي والعامل

The remainder when f(x) is divided by (x−a) is f(a). Also, (x−a) is a factor of f(x) exactly when f(a)=0.

الباقي عند قسمة f(x) على (x−a) هو f(a). ويكون (x−a) عاملًا لـ f(x) إذا وفقط إذا كان f(a)=0.

3. Transforming roots / تحويل الجذور

To obtain an equation whose roots are the old roots increased by k, put y = x + k, so x = y − k, and substitute into the original equation.

للحصول على معادلة جذورها تساوي الجذور القديمة مضافة إليها k، نضع y = x + k أي x = y − k، ثم نعوّض في المعادلة الأصلية.

4. Binomial expansion / مفكوك ذات الحدين

For |u| < 1 and any real n:

من أجل |u| < 1 ولأي عدد حقيقي n:

(1 + u)n = 1 + n u + [n(n−1)/2!] u² + [n(n−1)(n−2)/3!] u³ + …

For (a + bx)n, first write it as an(1 + (b/a)x)n. The expansion is valid when |(b/a)x| < 1.

من أجل (a + bx)n نكتبها أولًا على الصورة an(1 + (b/a)x)n، ويكون المفكوك صحيحًا عندما |(b/a)x| < 1.

5. Matrices / المصفوفات

For AB, the entry in row i and column j is the dot product of row i of A with column j of B. Eigenvalues solve det(A − λI) = 0; eigenvectors solve (A − λI)v = 0.

في حاصل الضرب AB، العنصر في الصف i والعمود j هو حاصل الضرب القياسي للصف i من A مع العمود j من B. تُحل القيم الذاتية من det(A − λI) = 0، والمتجهات الذاتية من (A − λI)v = 0.

Part 1 — Partial fractions / الكسور الجزئية

Q1 Partial fractions

Question. Resolve (x − 7)/(x² + 2x − 8) into partial fractions.

السؤال. حلّل الكسر (x − 7)/(x² + 2x − 8) إلى كسور جزئية.

Step 1 / الخطوة 1 — Factorise the denominator / حلّل المقام

We need two numbers whose product is −8 and whose sum is 2: these are 4 and −2. Hence x² + 2x − 8 = (x + 4)(x − 2).

نحتاج عددين حاصل ضربهما −8 ومجموعهما 2، وهما 4 و−2. إذن x² + 2x − 8 = (x + 4)(x − 2).

Step 2 / الخطوة 2 — Set up the partial fractions / اكتب صورة الكسور الجزئية

The factors are distinct and linear, so

العاملان خطيان ومختلفان، لذلك

(x − 7)/[(x + 4)(x − 2)] = A/(x + 4) + B/(x − 2)
Step 3 / الخطوة 3 — Clear the denominators / اضرب في المقام المشترك

Multiply both sides by (x + 4)(x − 2):

اضرب الطرفين في (x + 4)(x − 2):

x − 7 = A(x − 2) + B(x + 4)
Step 4 / الخطوة 4 — Substitute convenient values of x / عوّض بقيم مناسبة لـ x

Put x = 2:   2 − 7 = A(0) + B(6), so −5 = 6B and B = −5/6.

ضع x = 2:   2 − 7 = A(0) + B(6)، إذن −5 = 6B ومنها B = −5/6.

Put x = −4:   −4 − 7 = A(−6) + B(0), so −11 = −6A and A = 11/6.

ضع x = −4:   −4 − 7 = A(−6) + B(0)، إذن −11 = −6A ومنها A = 11/6.

Step 5 / الخطوة 5 — Check / تحقق

Coefficient of x: A + B = 11/6 − 5/6 = 1 ✓. Constant term: −2A + 4B = −22/6 − 20/6 = −42/6 = −7 ✓.

معامل x: A + B = 11/6 − 5/6 = 1 ✓. الحد الثابت: −2A + 4B = −22/6 − 20/6 = −42/6 = −7 ✓.

Answer: (x − 7)/(x² + 2x − 8) = 11/[6(x + 4)] − 5/[6(x − 2)].

الإجابة: (x − 7)/(x² + 2x − 8) = 11/[6(x + 4)] − 5/[6(x − 2)].

Q2 Partial fractions

Question. Resolve (4x² − 7x − 12)/[x(x + 2)(x − 3)] into partial fractions.

السؤال. حلّل الكسر (4x² − 7x − 12)/[x(x + 2)(x − 3)] إلى كسور جزئية.

Step 1 / الخطوة 1 — Identify the factors / حدّد العوامل

The denominator already has three distinct linear factors: x, (x + 2) and (x − 3). The numerator has degree 2, the denominator degree 3, so the fraction is proper.

المقام مكوّن من ثلاثة عوامل خطية مختلفة: x و(x + 2) و(x − 3). درجة البسط 2 ودرجة المقام 3، إذن الكسر صحيح.

Step 2 / الخطوة 2 — Set up the form / اكتب الصورة
(4x² − 7x − 12)/[x(x + 2)(x − 3)] = A/x + B/(x + 2) + C/(x − 3)
Step 3 / الخطوة 3 — Clear the denominators / اضرب في المقام المشترك
4x² − 7x − 12 = A(x + 2)(x − 3) + Bx(x − 3) + Cx(x + 2)
Step 4 / الخطوة 4 — Find A, B, C / أوجد A وB وC

Put x = 0:   −12 = A(2)(−3) = −6A, so A = 2.

ضع x = 0:   −12 = A(2)(−3) = −6A، إذن A = 2.

Put x = −2:   4(4) − 7(−2) − 12 = 18 = B(−2)(−5) = 10B, so B = 9/5.

ضع x = −2:   4(4) − 7(−2) − 12 = 18 = B(−2)(−5) = 10B، إذن B = 9/5.

Put x = 3:   4(9) − 7(3) − 12 = 3 = C(3)(5) = 15C, so C = 1/5.

ضع x = 3:   4(9) − 7(3) − 12 = 3 = C(3)(5) = 15C، إذن C = 1/5.

Step 5 / الخطوة 5 — Check / تحقق

Coefficient of x²: A + B + C = 2 + 9/5 + 1/5 = 2 + 2 = 4 ✓, which matches the numerator.

معامل x²: A + B + C = 2 + 9/5 + 1/5 = 2 + 2 = 4 ✓، وهو مطابق لبسط الكسر الأصلي.

Answer: 2/x + 9/[5(x + 2)] + 1/[5(x − 3)].

الإجابة: 2/x + 9/[5(x + 2)] + 1/[5(x − 3)].

Q3 Partial fractions

Question. Resolve x³/(x² − 1) into partial fractions.

السؤال. حلّل الكسر x³/(x² − 1) إلى كسور جزئية.

Step 1 / الخطوة 1 — Divide first / اقسم أولًا

The numerator has degree 3 and the denominator degree 2, so the fraction is improper. Divide:

درجة البسط 3 ودرجة المقام 2، إذن الكسر غير صحيح. نقسم:

x³ = x(x² − 1) + x

Therefore

لذلك

x³/(x² − 1) = x + x/(x² − 1)
Step 2 / الخطوة 2 — Factorise the remaining denominator / حلّل المقام المتبقي
x² − 1 = (x − 1)(x + 1)

So write

لذلك نكتب

x/[(x − 1)(x + 1)] = A/(x − 1) + B/(x + 1)
Step 3 / الخطوة 3 — Clear the denominators / اضرب في المقام المشترك
x = A(x + 1) + B(x − 1)
Step 4 / الخطوة 4 — Find A and B / أوجد A وB

Put x = 1:   1 = 2A, so A = 1/2.

ضع x = 1:   1 = 2A، إذن A = 1/2.

Put x = −1:   −1 = −2B, so B = 1/2.

ضع x = −1:   −1 = −2B، إذن B = 1/2.

Answer: x³/(x² − 1) = x + 1/[2(x − 1)] + 1/[2(x + 1)].

الإجابة: x³/(x² − 1) = x + 1/[2(x − 1)] + 1/[2(x + 1)].

Q4 Partial fractions

Question. Resolve x/[(x² + 1)(x² + 2)] into partial fractions.

السؤال. حلّل الكسر x/[(x² + 1)(x² + 2)] إلى كسور جزئية.

Step 1 / الخطوة 1 — Choose the correct form / اختر الصورة الصحيحة

Both x² + 1 and x² + 2 are irreducible quadratics over the real numbers, so each needs a linear numerator:

كلا المقدارين x² + 1 وx² + 2 تربيعي غير قابل للتحليل على الأعداد الحقيقية، لذا يحتاج كل منهما إلى بسط خطي:

x/[(x² + 1)(x² + 2)] = (Ax + B)/(x² + 1) + (Cx + D)/(x² + 2)
Step 2 / الخطوة 2 — Clear the denominators / اضرب في المقام المشترك
x = (Ax + B)(x² + 2) + (Cx + D)(x² + 1)
Step 3 / الخطوة 3 — Expand and compare coefficients / انشر وقارن المعاملات

Expanding the right-hand side:

بنشر الطرف الأيمن:

x = (A + C)x³ + (B + D)x² + (2A + C)x + (2B + D)

Comparing coefficients gives:

بمقارنة المعاملات نحصل على:

A + C = 0,   B + D = 0,   2A + C = 1,   2B + D = 0
Step 4 / الخطوة 4 — Solve the system / حلّ النظام

From A + C = 0 and 2A + C = 1: subtracting gives A = 1, hence C = −1.

من A + C = 0 و2A + C = 1: بالطرح نحصل على A = 1، ومنها C = −1.

From B + D = 0 and 2B + D = 0: subtracting gives B = 0, hence D = 0.

من B + D = 0 و2B + D = 0: بالطرح نحصل على B = 0، ومنها D = 0.

Answer: x/[(x² + 1)(x² + 2)] = x/(x² + 1) − x/(x² + 2).

الإجابة: x/[(x² + 1)(x² + 2)] = x/(x² + 1) − x/(x² + 2).

Part 2 — Division, remainder and roots of polynomials / القسمة والباقي وجذور كثيرات الحدود

Q5 Polynomial division

Question. Divide 2x³ + 2x² + 7 by (x − 2) and determine the quotient Q and the remainder R.

السؤال. اقسم 2x³ + 2x² + 7 على (x − 2) وحدّد خارج القسمة Q والباقي R.

Step 1 / الخطوة 1 — Write all coefficients / اكتب جميع المعاملات

Include the missing x term with coefficient 0: the coefficients are 2, 2, 0, 7. Use synthetic division with root 2.

أضف حد x المفقود بمعامل 0: المعاملات هي 2, 2, 0, 7. نستخدم القسمة التركيبية بالجذر 2.

 2 │   2    2    0    7
   │        4   12   24
   └────────────────────
       2    6   12   31
Step 2 / الخطوة 2 — Read the quotient and remainder / اقرأ خارج القسمة والباقي

The bottom row gives the quotient coefficients 2, 6, 12 (one degree lower than the cubic) and the remainder 31.

الصف الأخير يعطي معاملات خارج القسمة 2, 6, 12 (درجة أقل من الدرجة الثالثة بدرجة واحدة) والباقي 31.

Q = 2x² + 6x + 12,   R = 31
Step 3 / الخطوة 3 — Check by multiplying back / تحقق بالضرب العكسي
(x − 2)(2x² + 6x + 12) + 31 = 2x³ + 6x² + 12x − 4x² − 12x − 24 + 31 = 2x³ + 2x² + 7 ✓

Answer: Quotient Q = 2x² + 6x + 12; remainder R = 31.

الإجابة: خارج القسمة Q = 2x² + 6x + 12؛ والباقي R = 31.

Q6 Remainder theorem

Question. When 2x³ + kx² − 6 is divided by x + 1, the remainder is 3. Find k.

السؤال. عند قسمة 2x³ + kx² − 6 على x + 1 كان الباقي 3. أوجد k.

Step 1 / الخطوة 1 — Apply the remainder theorem / طبّق نظرية الباقي

Let f(x) = 2x³ + kx² − 6. Dividing by x + 1 = x − (−1) gives remainder f(−1).

لتكن f(x) = 2x³ + kx² − 6. القسمة على x + 1 = x − (−1) تعطي الباقي f(−1).

Step 2 / الخطوة 2 — Set the remainder equal to 3 / ساوِ الباقي بـ 3
f(−1) = 2(−1)³ + k(−1)² − 6 = −2 + k − 6 = k − 8

Given that the remainder is 3:

بما أن الباقي يساوي 3:

k − 8 = 3   ⇒   k = 11

Answer: k = 11.

الإجابة: k = 11.

Q7 Roots of polynomials

Question. If α is a root of x³ − 3x² + 4x − 8 = 0, find an equation for which 3α is a root.

السؤال. إذا كان α جذرًا للمعادلة x³ − 3x² + 4x − 8 = 0، فأوجد معادلة يكون 3α جذرًا لها.

Step 1 / الخطوة 1 — Introduce the new variable / أدخل المتغير الجديد

Let the new root be y = 3α. Then α = y/3.

ليكن الجذر الجديد y = 3α، إذن α = y/3.

Step 2 / الخطوة 2 — Substitute into the original equation / عوّض في المعادلة الأصلية

Since α satisfies α³ − 3α² + 4α − 8 = 0:

بما أن α تحقق α³ − 3α² + 4α − 8 = 0:

(y/3)³ − 3(y/3)² + 4(y/3) − 8 = 0
y³/27 − y²/3 + 4y/3 − 8 = 0
Step 3 / الخطوة 3 — Clear the fractions / تخلّص من الكسور

Multiply the whole equation by 27:

اضرب المعادلة كلها في 27:

y³ − 9y² + 36y − 216 = 0

Answer: The required equation is x³ − 9x² + 36x − 216 = 0 (using x as the variable).

الإجابة: المعادلة المطلوبة هي x³ − 9x² + 36x − 216 = 0 (باستخدام x كمتغير).

Q8 Remainder theorem

Question. Find the remainder when x2006 + x2005 + … + x + 1 is divided by x + 1.

السؤال. أوجد الباقي عند قسمة x2006 + x2005 + … + x + 1 على x + 1.

Step 1 / الخطوة 1 — Use the remainder theorem / استخدم نظرية الباقي

Let f(x) = x2006 + x2005 + … + x + 1. The remainder on division by x + 1 is f(−1).

لتكن f(x) = x2006 + x2005 + … + x + 1. الباقي عند القسمة على x + 1 هو f(−1).

Step 2 / الخطوة 2 — Evaluate the alternating sum / احسب المجموع المتناوب
f(−1) = (−1)2006 + (−1)2005 + … + (−1) + 1 = 1 − 1 + 1 − 1 + … − 1 + 1

There are 2007 terms (from exponent 0 to 2006). They form 1003 cancelling pairs (1 − 1), plus one final +1.

عدد الحدود 2007 حدًا (من الأس 0 إلى 2006). وتشكّل 1003 زوجًا متلاشيًا (1 − 1)، يتبقى بعدها حد أخير +1.

Step 3 / الخطوة 3 — Conclude / استنتج
f(−1) = 1

Answer: The remainder is 1.

الإجابة: الباقي هو 1.

Q9 Roots of polynomials

Question. Increase by 2 the roots of x⁴ − x³ − 10x² + 4x + 24 = 0 and hence solve it.

السؤال. زِد جذور المعادلة x⁴ − x³ − 10x² + 4x + 24 = 0 بمقدار 2، ثم حلّها.

Step 1 / الخطوة 1 — Set up the transformation / جهّز التحويل

We want the new roots to be y = x + 2, so x = y − 2. Substitute x = y − 2 into the equation.

نريد الجذور الجديدة y = x + 2، إذن x = y − 2. عوّض x = y − 2 في المعادلة.

Step 2 / الخطوة 2 — Expand each term / انشر كل حد
(y − 2)⁴ = y⁴ − 8y³ + 24y² − 32y + 16
−(y − 2)³ = −y³ + 6y² − 12y + 8
−10(y − 2)² = −10y² + 40y − 40
+4(y − 2) = 4y − 8    and    +24
Step 3 / الخطوة 3 — Add and simplify / اجمع وبسّط

Adding the five lines and collecting like terms:

بجمع الأسطر الخمسة وتجميع الحدود المتشابهة:

y⁴ + (−8 − 1)y³ + (24 + 6 − 10)y² + (−32 − 12 + 40 + 4)y + (16 + 8 − 40 − 8 + 24) = 0
y⁴ − 9y³ + 20y² = 0
Step 4 / الخطوة 4 — Solve the transformed equation / حلّ المعادلة المحوّلة
y²(y² − 9y + 20) = 0   ⇒   y²(y − 4)(y − 5) = 0

Hence y = 0 (double root), y = 4, y = 5.

إذن y = 0 (جذر مكرر)، y = 4، y = 5.

Step 5 / الخطوة 5 — Return to x / ارجع إلى x

Using x = y − 2:

باستخدام x = y − 2:

y = 0 → x = −2;   y = 4 → x = 2;   y = 5 → x = 3

Answer: The transformed equation is y⁴ − 9y³ + 20y² = 0. The roots of the original equation are x = −2 (double), x = 2 and x = 3.

الإجابة: المعادلة المحوّلة هي y⁴ − 9y³ + 20y² = 0. وجذور المعادلة الأصلية هي x = −2 (مكرر)، x = 2، x = 3.

Q10 Binomial expansion

Question. Write down the first 4 terms in ascending powers of x of the binomial expansion of (1 − x)−2, and clearly state the range of values for which the expansion is valid.

السؤال. اكتب أول 4 حدود بالقوى التصاعدية لـ x في مفكوك (1 − x)−2، وحدّد بوضوح نطاق القيم التي يكون فيها المفكوك صحيحًا.

Step 1 / الخطوة 1 — Match the standard form / طابق الصورة القياسية

Use (1 + u)n with n = −2 and u = −x.

استخدم (1 + u)n مع n = −2 وu = −x.

Step 2 / الخطوة 2 — Compute the coefficients / احسب المعاملات

First term: 1.

الحد الأول: 1.

Second term: n u = (−2)(−x) = 2x.

الحد الثاني: n u = (−2)(−x) = 2x.

Third term: [n(n−1)/2!] u² = [(−2)(−3)/2] x² = 3x².

الحد الثالث: [n(n−1)/2!] u² = [(−2)(−3)/2] x² = 3x².

Fourth term: [n(n−1)(n−2)/3!] u³ = [(−2)(−3)(−4)/6] (−x)³ = (−4)(−x³) = 4x³.

الحد الرابع: [n(n−1)(n−2)/3!] u³ = [(−2)(−3)(−4)/6] (−x)³ = (−4)(−x³) = 4x³.

Step 3 / الخطوة 3 — State the range of validity / حدّد نطاق الصلاحية

The expansion is valid for |u| < 1, i.e. |−x| < 1, so |x| < 1.

المفكوك صحيح عندما |u| < 1، أي |−x| < 1، ومنها |x| < 1.

Answer: (1 − x)−2 = 1 + 2x + 3x² + 4x³ + …, valid for |x| < 1.

الإجابة: (1 − x)−2 = 1 + 2x + 3x² + 4x³ + …، صحيح عندما |x| < 1.

Q11 Binomial expansion

Question. Write down the first 4 terms in ascending powers of x of the binomial expansion of (2 + 3x)−2, and clearly state the range of values for which the expansion is valid.

السؤال. اكتب أول 4 حدود بالقوى التصاعدية لـ x في مفكوك (2 + 3x)−2، وحدّد بوضوح نطاق القيم التي يكون فيها المفكوك صحيحًا.

Step 1 / الخطوة 1 — Factor out the constant / أخرج العامل الثابت

Write (2 + 3x)−2 = 2−2(1 + 3x/2)−2 = (1/4)(1 + u)−2, where u = 3x/2.

اكتب (2 + 3x)−2 = 2−2(1 + 3x/2)−2 = (1/4)(1 + u)−2، حيث u = 3x/2.

Step 2 / الخطوة 2 — Expand with n = −2 / انشر باستخدام n = −2

The bracket gives:

القوس يعطي:

1 + (−2)u + [(−2)(−3)/2]u² + [(−2)(−3)(−4)/6]u³
= 1 − 2u + 3u² − 4u³

Substituting u = 3x/2:

بالتعويض u = 3x/2:

1 − 3x + 3(9x²/4) − 4(27x³/8) = 1 − 3x + 27x²/4 − 27x³/2
Step 3 / الخطوة 3 — Multiply by 1/4 / اضرب في 1/4
(2 + 3x)−2 = 1/4 − 3x/4 + 27x²/16 − 27x³/8 + …
Step 4 / الخطوة 4 — Range of validity / نطاق الصلاحية

Require |u| < 1, i.e. |3x/2| < 1, which gives |x| < 2/3.

نشترط |u| < 1، أي |3x/2| < 1، ومنها |x| < 2/3.

Answer: (2 + 3x)−2 = 1/4 − 3x/4 + 27x²/16 − 27x³/8 + …, valid for |x| < 2/3.

الإجابة: (2 + 3x)−2 = 1/4 − 3x/4 + 27x²/16 − 27x³/8 + …، صحيح عندما |x| < 2/3.

Q12 Binomial expansion
